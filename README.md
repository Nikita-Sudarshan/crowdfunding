# 🚀 Simple Crowdfunding Smart Contract

## 📄 Project Description

This is a basic crowdfunding DApp built using Solidity. The smart contract allows people to contribute Ether towards a funding goal within a limited time. If the goal is met before the deadline, the contract owner can withdraw the funds.

## 🎯 Project Vision

To empower developers and creators with a minimalistic, transparent, and gas-efficient crowdfunding smart contract for quick deployment on EVM-compatible blockchains.

## 🔑 Key Features

- **Contribution Logic**: Users can fund the campaign before the deadline.
- **Withdrawal Rights**: Only the campaign owner can withdraw if the goal is met.
- **Transparent Data**: Anyone can query campaign details.

## 🔭 Future Scope

- Add refund logic for contributors if the goal is not reached.
- Support for multiple campaigns or project tiers.
- Integration with frontend (React/Next.js).
- Use Chainlink price feeds or oracles for dynamic ETH-USD tracking.
- Add NFTs or rewards for contributors.
